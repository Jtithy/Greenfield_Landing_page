# 🏫 Greenfield School Website

A modern, responsive and user-friendly school website designed to present Greenfield School's academic programs, educational services, facilities, admission information and school activities.

The website provides parents, guardians and visitors with an easy way to explore the school, learn about its educational environment and contact the school administration.

## 🌟 Project Overview

**Greenfield School** is a kindergarten to primary-level school website (KG – Class 5) designed to provide essential school information through a clean and organized interface.

The website focuses on showcasing the school's educational programs, student development activities, facilities, admission process and communication services.

## 🚀 Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/your-username/Greenfield-School.git
```

**2. Navigate to the project directory**

```bash
cd Greenfield-School
```

**3. Open the project**

Open `index.html` in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
